TOCTOU
Dùng một chiến lược khác nhau theo chiều:

S3 → EFS: EFS write có thể dùng os.link() khi không overwrite. Với overwrite, tránh race bằng rename/backup nhưng vẫn cần xem xét thư mục cha có thể đổi.
EFS → S3: over_write=false nên dùng conditional write hoặc nhận diện object mới atomically. Không thể chỉ dùng HeadObject + upload_file.
S3 object được thay đổi trong khi tải: dùng ETag/version ID để pin nội dung cho toàn batch.
EFS source: snapshot thông tin file hoặc mở file trước rồi upload; tránh kiểm tra source rồi mở lại sau.
