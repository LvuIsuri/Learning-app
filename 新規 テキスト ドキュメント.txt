ổng hợp yêu cầu cho chức năng copy folder:

Không đổi cách copy file hiện tại. Nếu nguồn là file thì xử lý như bây giờ.
Folder EFS: chỉ copy các file nằm trực tiếp bên trong; không đi vào thư mục con.
Folder S3:
s3://bucket và s3://bucket/ đều chỉ bucket root.
Nếu có prefix, prefix bắt buộc kết thúc bằng /, ví dụ s3://bucket/data/.
Chỉ copy các object trực tiếp trong prefix; bỏ qua thư mục con và object marker kết thúc bằng /.
Không có file phù hợp thì báo lỗi, trả 1.
Đích: phải là thư mục. Kiểm tra thư mục đích tồn tại và có quyền ghi/thực thi; nếu không có quyền thì log lỗi và trả -1, như đoạn bạn đang chọn.
Xung đột file: nếu overwrite=false và có ít nhất một file đích đã tồn tại, dừng trước khi copy và trả 1. Nếu overwrite=true, cho phép ghi đè.
Mã lỗi: lỗi tham số, nguồn không tồn tại hoặc file đích đã có trả 1; lỗi quyền, kết nối hoặc truyền tải trả -1.
Ví dụ s3://bucket/data/ chỉ lấy data/a.csv, không lấy data/sub/b.csv.
