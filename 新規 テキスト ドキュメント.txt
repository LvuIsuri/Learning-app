4. S3 → EFS
copy_s3_to_efs()

Copy file:

Parse bucket/key bằng split_s3_uri().
Kiểm tra destination:
Nếu destination là thư mục, thêm tên file.
Destination directory phải tồn tại và có quyền ghi.
Gọi head_object() để xác nhận S3 object tồn tại.
Tạo temporary file .filename.random.part trong cùng thư mục destination.
Download vào temporary file.
Đổi permission thành 0664.
Với true, dùng os.replace() để replace.
Với false, dùng os.link() để tránh overwrite nếu file vừa được tạo.
Xóa temporary file.
Copy folder:

Nhận diện khi S3 key rỗng hoặc kết thúc /.
Destination EFS phải là thư mục tồn tại.
Dùng list_objects_v2 paginator để lấy tất cả object.
Kiểm tra toàn bộ destination trước khi download.
Copy từng object bằng cùng cơ chế temporary file.
Không copy object key kết thúc /.
5. EFS → S3
copy_efs_to_s3()

Copy file:

Kiểm tra source EFS tồn tại.
Parse destination S3 bucket/key.
Nếu destination không có key, dùng tên file source.
Với overwrite=false, kiểm tra object bằng head_object().
Upload bằng upload_file().
Copy folder:

Thu thập toàn bộ file bằng rglob("*").
Destination prefix phải kết thúc /.
Tạo danh sách destination key theo cấu trúc tương đối.
Với overwrite=false, kiểm tra object đã tồn tại bằng list_objects_v2.
Upload từng file.
Kết quả trả về
0: copy thành công.
1: tham số, path, URI, quyền overwrite hoặc trạng thái resource không hợp lệ.
-1: exception ngoài dự kiến, S3/EFS/I/O hoặc transfer thất bại.
