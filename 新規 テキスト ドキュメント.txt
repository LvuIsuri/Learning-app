jmeterはコマンドで操作する。あらかじめシナリオを作成しログはファイルで保存しコンソールに結果表示しない。(リスナーを削除する)
以下のような形
　JVM ARGS="-Xms4g -Xmx4g" jmeter -n -t /シナリオパス.jmx -l /ログ保存先.jtl
請求結果連携はレスポンスがzipファイルなのでJmeter側でレスポンスデータを即時破棄する指定を行う
　JVM ARGS="-Xms4g -Xmx4g" jmeter -n -t /シナリオパス.jmx -l /ログ保存先.jtl -Jjmeter.max bytes to store per sample=1
　
カウンター
　HTTPリクエストからカウンターの追加を行う
　Starting value　開始
　Increment　カウント増分
　Maximum value　最大
　Number format　0埋め桁数
　Exported Variable Name　変数名
　Trac counter independently for each user
　
確認
　ECSタスクのメトリクスを確認する

レポート項目の説明
　Label　サンプルの名前
　#Samples　リクエスト総数
　Average　レスポンス平均値
　Median　レスポンス中央値
　90％Line　90％のユーザ処理完了時の時間
　95％Line　95％のユーザ処理完了時の時間
　99％Line　99％のユーザ処理完了時の時間
　Min　最小値
　Max　最大値
　Error％　エラーリクエスト数割合(500系かタイムアウト)
　Throughput　1秒または1分あたりに処理したリクエスト数
　Received KB/sec　1秒あたりにサーバーから受信したデータ量
　Sent KB/sec　1秒あたりにサーバーから受信したデータ量
